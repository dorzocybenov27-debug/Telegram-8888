# Корпоративный Аналитик Переписок в Telegram (Спринт 1)

Система автоматизированного сбора, архивации и интеллектуального анализа корпоративных диалогов на базе **aiogram 3**, **SQLAlchemy** и **PostgreSQL**. Интегрирована с нейросетью **YandexGPT** для контент-анализа собранных текстовых данных.

## Архитектура решения и выполненные задачи
1. **Модуль Базы Данных (`database.py`):** Реализована схема на базе PostgreSQL. Добавлен уникальный составной индекс на связку параметров `chat_id + message_id` (защита от дублирования данных методом Upsert). Сохраняется оригинальный временной штамп сообщения из Telegram.
2. **Модуль Сбора и Администрирования (`admin_bot.py`):** Единый асинхронный модуль управления. Перехватывает сообщения из привязанных групп, определяет тип вложений и физически скачивает фотографии, документы и голосовые сообщения в локальное хранилище `downloads/`.
3. **Модуль ИИ (`ai_assistant.py`):** Реализована интеграция с моделью YandexGPT Cloud для суммаризации переписок.
4. **Обход ограничений сети:** Внедрена поддержка `TelegramAPIServer` (кастомный эндпоинт), гарантирующая стабильный запуск системы из изолированной среды WSL без таймаутов.

## Пошаговое развертывание проекта

### 1. Подготовка окружения
Убедитесь, что у вас установлена СУБД PostgreSQL и развернуто виртуальное окружение Python:
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. Конфигурация переменных окружения
Создайте в корне проекта файл `.env` со следующей структурой (пример заполнения):
```env
# Параметры подключения к СУБД PostgreSQL
DATABASE_URL=postgresql+asyncpg://postgres:ваш_пароль@localhost:5432/имя_базы

# Ключи Telegram Bot API (от @BotFather и my.telegram.org)
ADMIN_BOT_TOKEN=8835743233:AAGycrRWk7fJsCEp8...
ADMIN_IDS=[7541779718]

# Параметры интеграции с ИИ Yandex Cloud
YC_API_KEY=AQVN1TfTuZS97xBMZ3qyx...
FOLDER_ID=b1gss1t2kjlsuv9fes60
```

### 3. Запуск системы
Запустите главный асинхронный цикл приложения:
```bash
python main.py
```

## Доступные команды Администратора в Telegram
* `/start` — Проверка статуса работоспособности системы сбора.
* `/export <chat_id> <ДД.ММ.ГГГГ> <ДД.ММ.ГГГГ>` — Выгрузка логов переписки и путей к медиафайлам в CSV-документ за выбранный временной период с валидацией границ дат.
* `/ask <chat_id> <вопрос>` — Отправка недельного контекста чата в YandexGPT для генерации аналитического ответа по переписке.
