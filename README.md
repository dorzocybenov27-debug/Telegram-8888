# Корпоративный Аналитик Переписок в Telegram 

Система автоматизированного сбора, архивации и интеллектуального анализа корпоративных диалогов на базе **aiogram 3**, **Telethon (MTProto)**, **SQLAlchemy** и **PostgreSQL**. Интегрирована с нейросетью **YandexGPT** для контент-анализа собранных текстовых данных.

## Архитектура решения и выполненные задачи
1. **Модуль Базы Данных (`database.py`):** Реализована схема на базе PostgreSQL. Добавлен уникальный составной индекс на связку параметров `chat_id + message_id` (защита от дублирования данных методом атомарного Upsert). Сохраняется оригинальный временной штамп сообщения из Telegram без учета временной зоны.
2. **Модуль Сбора и Администрирования (`admin_bot.py`):** Асинхронный модуль управления на Bot API. Перехватывает сообщения из привязанных групп, определяет тип вложений, безопасно извлекает структуры реакций и автоматически раскладывает фотографии, документы и голосовые сообщения по индивидуальным именным папкам внутри хранилища `downloads/`.
3. **Модуль Клиентского Сбора (`userbot.py`):** Интегрирован юзербот на базе Telethon. При каждом перезапуске считывает из БД список отслеживаемых чатов и принудительно синхронизирует историю (ликвидация простоя), автоматически скачивая все сообщения, отправленные во время офлайн-статуса системы. Снабжен жестким фильтром входящего трафика для полной изоляции личных переписок разработчика.
4. **Модуль ИИ (`ai_assistant.py`):** Реализована интеграция с моделью YandexGPT Cloud для суммаризации и аналитики переписок.
5. **Обход ограничений сети:** Внедрена поддержка `TelegramAPIServer` для Bot API и протокол маскировки трафика `connection=ConnectionTcpObfuscated` для клиентского API. Это гарантирует стабильный параллельный запуск системы из изолированной среды WSL без сетевых таймаутов.

## Пошаговое развертывание проекта

### 1. Подготовка окружения
Убедитесь, что у вас установлена СУБД PostgreSQL и развернуто виртуальное окружение Python:
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. Конфигурация переменных окружения
Создайте в корне проекта файл `.env` со следующей структурой:
```env
# Параметры подключения к СУБД PostgreSQL
DATABASE_URL=postgresql+asyncpg://postgres:ваш_пароль@localhost:5432/имя_базы

# Ключи Telegram Bot API и Клиентского MTProto API
ADMIN_BOT_TOKEN=8737235241:AAGxP5rZRo0RLIKu5h...
ADMIN_IDS=1222413664
PHONE=+79834524898
API_ID=33489928
API_HASH=c8027f90a8ae98283e6bc4f3f6044e8b

# Параметры интеграции с ИИ Yandex Cloud
YC_API_KEY=AQVN1TfTuZS97xBMZ3qyx...
FOLDER_ID=b1gss1t2kjlsuv9fes60
```

### 3. Запуск системы
Запустите главный асинхронный цикл приложения, который параллельно поднимет базу данных, админ-бота и юзербота:
```bash
python main.py
```
*При первом запуске юзербот в интерактивном режиме запросит в терминале 5-значный код верификации и облачный (двухфакторный) пароль аккаунта. После успешного входа создается файл `session_collector.session`, и повторный ввод данных при перезапусках больше не требуется.*

## Доступные команды Администратора в Telegram
* `/start` — Проверка статуса работоспособности системы сбора.
* `/export <chat_id> <ДД.ММ.ГГГГ> <ДД.ММ.ГГГГ>` — Выгрузка логов переписки, реакций и путей к медиафайлам в CSV-документ за выбранный временной период с полной валидацией границ дат и ограничением на максимальный период (1 год).
* `/ask <chat_id> <вопрос>` — Отправка недельного контекста чата из PostgreSQL в YandexGPT для генерации аналитического ответа по переписке.
